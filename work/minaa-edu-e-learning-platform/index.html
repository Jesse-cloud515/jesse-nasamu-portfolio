Minaa Edu e-learning platform

A self-paced learning platform for Good Agronomic Practice, with courses, a lesson player, assessments and verifiable certificates.

Discipline
Web development · UI/UX design
My role
Design and development
When
Aug 2026
Tools
HTML, CSS, JavaScript, Node.js (build script), Netlify
Visit the live site

The challenge

Farmers, students and extension workers need practical agronomy training they can take at their own pace, with proof of what they've learned.

My approach

A plain HTML, CSS and JavaScript site with no framework or server, so it loads fast and can be hosted anywhere. All course content lives in editable data files.

Process

  1. Built a course catalogue with live search and filters for learning area, difficulty and duration, kept in the URL so a filtered view can be shared.
  2. Built the lesson player: video, reading and exercise stages, a curriculum sidebar with progress, notes, resources and transcripts.
  3. Added assessments that draw scenario questions at random from a question bank, with explanations, review and retakes.
  4. Added a learner dashboard, printable certificates and a public page to verify a certificate by its ID.
  5. Added a community section, pricing and checkout pages, and a small build script that writes shared navigation and course data into every page.

The solution

A complete learning site: five learning areas, course pages, the lesson player, exams, a dashboard and certificates, published on Netlify.
